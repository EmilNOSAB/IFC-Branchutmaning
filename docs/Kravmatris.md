# Kravmatris IDS -> DGN -> Item Type -> IFC

Genererad av `tools/make_docs.py` ur `input/Branschutmaningen_2026.ids` (oförändrad) och konfigurationen.

IFC-filen skapas enbart av MicroStations exportör och ändras inte. Kolumnen *Mekanism* anger hur exportören ska få fram kravet ur DGN:en. "prov Pxx" är objekt i exportörsprovet (`microstation/probe_exporter.py`), se `docs/IFC_relationer.md`. Kolumnen *Verklig export* är resultatet för den oförändrade exportfilen från MicroStation 2026, körning 1 (`docs/evidence/microstation2026_run1/`). I den körningen saknades "IFC Classification" i DGN:en.
